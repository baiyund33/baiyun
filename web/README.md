# 白云 Web

React + TypeScript 白云桌面界面：注册、登录、联系人、好友申请及资料管理。

## 开发

```powershell
cd E:\code\baiyun\web
npm install
npm run dev
```

访问 http://localhost:3000。Vite 将 /api/user 转发到8888，/api/social 转发到8889；启动对应API及其RPC依赖。用户和好友API的JWT密钥必须一致。

登录后进入桌面布局。左侧好友列表滚动到底部自动加载下一页，每次20位；搜索框过滤已加载好友的昵称或ID。失败可重试，点击“联系人”从第一页重新加载；搜索时可点击“加载更多好友”。点击好友在右侧查看资料并可确认单向删除，对方关系保留，删除成功刷新列表。加号打开添加好友，点击“好友通知”刷新收到的申请（再次点击也会刷新），可接受或拒绝，接受后刷新好友列表。顶部头像或设置图标打开个人资料。聊天和全量搜索尚未提供。

生产构建 npm run build，输出 dist。开发代理不会包含在构建产物中，服务器需配置两条API反向代理。

好友通知也采用无限滚动，每批20条，失败可重试。点击通知入口从第一页重新加载；接受/拒绝更新当前记录，保留已加载的其他通知。

详见 [开发与验证记录](../docs/development/web-auth.md) 和 [部署说明](../docs/deploy/web.md)。TypeScript/构建与模拟接口浏览器验证通过，真实后端联调待验证。
