先理解 **WebSocket 是一条可以持续收发消息的连接**。

你现在的 HTTP 调用是：

```
前端发请求 → 后端返回响应 → 本次请求结束
```

聊天使用 WebSocket：

```
前端建立连接 ⇄ 后端
              持续保持
前端可以发送消息，后端也能主动推送消息
```

例如 A 给 B 发消息：

```
A 的浏览器 → WebSocket 服务 → B 的浏览器
```

B 无需反复发送“有没有新消息”的请求，服务器可以直接推送。

结合当前项目，需要先认识这些概念：

| 概念                 | 含义                                    |
| ------------------ | ------------------------------------- |
| 握手                 | 浏览器先发送 HTTP 请求，请求建立 WebSocket 连接      |
| 升级                 | 服务端同意后返回 `101`，开始使用 WebSocket 协议      |
| `ws://` / `wss://` | WebSocket 地址；`wss://` 使用加密连接，类似 HTTPS |
| JWT 鉴权             | 建立连接前确认用户身份                           |
| 连接管理               | 服务端记录“哪个用户对应哪条连接”，才能推送给指定用户           |
| 心跳                 | 定期检查连接是否还正常，断线后清理连接                   |
