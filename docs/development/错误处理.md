#### 1.status.FromError(err)
这段用于：**如果 `err` 已经是 gRPC 状态错误，就直接返回，保留原来的错误码和提示。**

```
if _, ok := status.FromError(err); ok {
	return nil, err
}
```

|部分|含义|
|---|---|
|`status.FromError(err)`|尝试将错误转换为 gRPC 状态，返回状态对象和 `ok`|
|`_`|忽略状态对象，这里不需要读取它|
|`ok`|表示是否识别为 gRPC 状态错误|
|`return nil, err`|原样返回错误|

例如事务中返回：

```
status.Error(codes.Aborted, "申请状态已变化，请刷新")
```

这段会保留 `Aborted` 和原提示；普通数据库错误则继续往下处理，转换为：

```
status.Error(codes.Internal, "处理好友申请失败")
```
