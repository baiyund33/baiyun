#### 1.为什么 Page int32 `form:"page,default=1"`  PageSize int32 `form:"pageSize,default=20"`  使用form?
在 go-zero 中，它用于读取 URL 查询参数，也支持表单参数。

你的接口是 GET，例如：

```
GET /api/social/friend/applications?page=2&pageSize=10
```

对应：

```
Page     int32 `form:"page,default=1"`
PageSize int32 `form:"pageSize,default=20"`
```

- `page=2` → `Page` 得到 `2`。
- `pageSize=10` → `PageSize` 得到 `10`。
- 未传参数 → 使用默认值 `1` 和 `20`。

`json` 标签用于读取 JSON 请求体；这里的分页参数放在 URL 中，所以使用 `form`。
