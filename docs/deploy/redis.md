# Redis 接入与部署记录

状态：RPC 客户端初始化已存在，缓存业务未实现；服务器版本、部署和持久化待核实。

1. **作用与使用方**：RPC ServiceContext 保存 Redis 客户端。当前 CRUD 使用 MySQL，尚未写 Redis 缓存逻辑。
2. **环境与版本**：应用 go-zero 1.10.3；Redis 的实际版本、系统和运行方式未知。
3. **文件与配置**：RPC etc/user.yaml 的 Redisx.Host、Type、Pass；Type=node。凭据由用户提供，运行时挂载配置。
4. **部署步骤**：沿用既有实例，先核对服务名、版本、地址、认证和运行状态，不另建假设的容器。实际安装命令待补。
5. **应用接入**：redis.MustNewRedis(c.Redisx) 默认启动检查连接，失败会中止 RPC 启动。容器填写可达的外部地址，同一网络内才可用对应容器名。
6. **验证**：已有 Redis 管理客户端执行 PING，预期 PONG；RPC 启动无 Redis 错误。密码经客户端认证配置提供，不写入示例命令。实际验证结果待确认。
7. **日常操作与排错**：服务器日志、停止和重启按实际部署方式待补；超时查网络，NOAUTH/WRONGPASS 查认证。应用日志命令见 [Docker 部署](user-docker.md)。
8. **数据与变更影响**：RDB/AOF、数据卷和备份待确认。目前无缓存键协议，不清空数据排错。
